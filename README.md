# Coffee-Shop-Simulator
A text-based coffee shop simulation developed in Python


OVERVIEW

This project simulates a coffee shop ordering experience through a text-based interface. 
Users can interact with the program to make selections and complete orders.

FEATURES

Interactive user input
Coffee shop ordering functionality
Order processing
Order total calculation
Technologies
Python
Object-Oriented Programming


WHAT I LEARNED
Applying object-oriented programming concepts
Organizing code into classes and methods
Working with user input and program logic
Debugging and testing Python applications
